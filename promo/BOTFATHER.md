# Оформление бота в @BotFather

Все команды отправляются в чат с @BotFather. После команды он спросит, какого бота менять, — выбери своего.

## Аватарка — `/setuserpic`
Отправь картинку `promo/bot-avatar.png` (как фото, не файлом).

## Описание — `/setdescription`
Его видят люди, которые открыли бота, но ещё не нажали «Старт» (до 512 символов):

```
🚗 Генератор номеров — крути автомобильные номера и собирай коллекцию!

🎰 Жми — и выпадает номер. Блатные серии АМР, ЕКХ, ООО, три семёрки, зеркальные цифры — чем реже комбинация, тем дороже номер.
💰 Продавай номера, открывай такси, полицейские и военные номера, номера Беларуси.
📋 Ежедневные задания, сейф, автопродажа и каталог редкостей.

Нажми «Играть» 👇
```

## Короткое описание — `/setabouttext`
Видно в профиле бота и при пересылке (до 120 символов):

```
Крути автономера, лови блатные серии и собирай коллекцию 🚗
```

## Прямая ссылка в игру — `/newapp`
1. `/newapp` → выбери бота.
2. Название: `Генератор номеров`
3. Описание: `Крути номера, лови блатные серии и собирай коллекцию`
4. Фото 640×360: `promo/app-banner.png`
5. GIF: отправь `/empty`
6. Ссылка: `https://tikhonfaustov.github.io/plates-game/`
7. Короткое имя: `play`

Получится ссылка `https://t.me/ИМЯ_БОТА/play` — она сразу открывает игру.

### Чтобы ссылка открывала игру на весь экран
`/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** (ссылка та же) и включи **Fullscreen** (если такой пункт есть в твоей версии BotFather).
Игра и сама просит полный экран на телефонах.

## Кнопка «Играть» в чате (если ещё не сделал)
`/mybots` → бот → **Bot Settings** → **Menu Button** → ссылка `https://tikhonfaustov.github.io/plates-game/` → название `Играть`.
