# Генератор номеров — мини-приложение для Telegram

Копия игры [play.mitrofanof.ru](https://play.mitrofanof.ru/) для Telegram. Нажимаешь в любом месте экрана —
выпадает автомобильный номер. Номер оценивается по комбинациям (777, 001, АМР 77, зеркальные цифры…),
региону и редкости. Номера копятся в коллекции: их можно продать, спрятать в сейф или продавать автоматически.

## Что есть в игре
- Генератор: прокрут за 3 000 ₽, выбор страны (Россия, Беларусь), типа номера и региона.
- Типы номеров: гражданский, такси (с 1 000 номеров), полиция (с 5 000), военный (с 10 000), белорусский.
- 5 редкостей: Обычный, Необычный, Редкий, Эпический, Легендарный. Шансы подобраны под оригинал.
- Коллекция (50 мест), сейф (5 мест), быстрая продажа по фильтрам.
- Автопродажа — 9 уровней за $.
- Улучшения коллекции (₽) и сейфа ($).
- Ежедневные задания: 2 обычных (50 000 ₽), 1 сложное (50 $), бонус за все.
- Каталог редкостей, статистика с уровнями, 5 тем, настройки.

## Формула цены
```
цена = (базовая стоимость + сумма комбинаций) × комбо × регион × код × класс
```
- комбо: 1 комбинация ×1, 2 — ×1.5, 3 — ×2.25
- регион: престиж региона (Москва ×5)
- код: основной код региона ×1, поздние коды дешевле (799 — ×0.47)
- класс: обычный ×1, необычный ×1.05, редкий ×1.2, эпический ×5, легендарный ×50

## Как запустить на компьютере

```bash
node tools/serve.js
```

Потом открой http://localhost:5173. Вне Telegram прогресс сохраняется в браузере.

| `js/data.js` | регионы, коды, множители, блатные серии |

## Как подключить к Telegram

Telegram открывает мини-приложение только по ссылке **https://**, поэтому игру сначала надо выложить в интернет.

### 1. Выложить игру (бесплатно, GitHub Pages)
1. Зарегистрируйся на github.com и создай публичный репозиторий, например `plates-game`.
2. Загрузи туда все файлы этой папки (Add file → Upload files).
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту игра будет по адресу `https://ТВОЙ_ЛОГИН.github.io/plates-game/`.

### 2. Создать бота
1. В Telegram открой [@BotFather](https://t.me/BotFather) → `/newbot` → имя и username (должен кончаться на `bot`).
2. `/mybots` → твой бот → Bot Settings → Menu Button → ссылка на игру, название «Играть».
3. (По желанию) `/newapp` → прямая ссылка вида `t.me/твой_бот/play`.
